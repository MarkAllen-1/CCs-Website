# Creative Contact Solutions website

Static site for creativecontactsolutionsllc.com, hosted on GitHub Pages. No build step: edit the HTML and CSS, then commit and push.

- `index.html`: the whole site (pitch, problem, example, proof, pricing, services, about, FAQ, contact)
- `assets/css/site.css`: styles and brand colors
- `assets/js/site.js`: mobile menu and contact form (opens the visitor's email app; nothing is stored)
- `assets/img/`: logo and icons
- `assets/downloads/`: the sample report PDF
- `CNAME`: the custom domain for GitHub Pages

Prices and offers live in the Pricing section of `index.html`.

Do not add the working calculator workbook, the sample workbook password, or client data to this repository. The repository is public.
